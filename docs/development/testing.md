# 测试

测试围绕可观察的核心行为组织，不按测试数量评价覆盖程度。不为常量、访问器或库自身的类型校验单独堆叠用例。

## 覆盖重点

| 测试文件 | 负责的行为 |
| --- | --- |
| `test/config.test.js` | 默认 read、/root 与多目录、三类权限、凭据互斥、错误脱敏、来源优先级和 SSH 子集 |
| `test/known-hosts.test.js` | 精确/哈希匹配、端口/IPv6、撤销优先、有效公钥下的不支持格式拒绝 |
| `test/tools.test.js` | 读取工具、统一 read 授权、深路径、目录分页、UTF-8、大文件范围读取和独立搜索预算 |
| `test/mutate.test.js` | 创建/覆盖/追加、mkdir、跨挂载移动、单独 delete 权限、递归预校验和部分修改提示 |
| `test/archive.test.js` | gzip/tar/tar.gz/zip 的读/tail/解压、路径/链接/CRC/炸弹拒绝、ZIP 成员选择和压缩日志搜索 |
| `test/limits.test.js` | 扫描和输出预算、空/特殊文件计数、并发队列、取消、迟到回调与断线恢复 |
| `test/ssh.test.js` | 本机真实 SSH 握手、认证方式、密钥拒绝、共享连接和多服务器作用域 |
| `test/stdio.test.js` | 官方 SDK 发现十二工具及修改注解、默认只读、真实 SFTP 写入/追加/移动/解压/删除、4 MiB 传输、旧协议与取消 |

单元/mock 测试不访问外部网络。回环集成使用 ssh2.Server，仅监听 `127.0.0.1` 随机端口和临时 Agent 端点；它验证真实 SSH/SFTP 协议，文件后端使用可控的内存树，不能代替所有 OpenSSH/OS 行为。

密钥和密码在运行时生成并清理，不读取开发者的私钥或 Agent，不连接个人配置中的服务器。临时身份生成与模拟文件系统分别位于 `test/helpers/`，避免基础单元测试依赖完整网络夹具。

## 运行

开发检查使用 Node.js 22.13+（22.x）或 24+；ESLint 10 不支持较早的 22.x。MCP 运行时仍要求 Node.js >= 22。

```bash
npm ci
npm test
npm run lint
npm run test:stdio
```

发布前运行 `npm run test:package -- /absolute/path/package.tgz`，将路径替换为 `npm pack` 输出的实际文件。它从空目录使用 npm exec（npx 的底层入口）安装 tarball，以密码、环境变量密码、私钥、加密私钥和 SSH Agent 验证工具及拒绝行为。首次空缓存需连接 npm registry，SSH/SFTP 及修改只使用本机隔离夹具。

发布后的 registry 验收见[发布说明](releasing.md)。验收临时目录包含空格，覆盖安装路径兼容性。

完整测试需要允许本机端口和套接字监听。受限沙箱可在明确允许本机回环的环境执行；不要通过跳过认证或安全测试来使检查变绿。

## 增删测试的标准

- 每个工具应有正常、拒绝和有意义的边界场景，公共策略集中测试，工具独立权限仍逐个确认。
- 优先断言返回结果、错误码、是否真正读过数据、取消后是否可继续调用等外部行为。
- 身份格式测试应使用有效公钥，使失败确实来自目标格式规则。
- 用可控回调模拟迟到 I/O；避免靠短暂 sleep 猜测执行顺序。
- 删除重复的认证全工具遍历、与上层行为重叠的内部状态测试，以及只与实现常量互相比对的断言。

## 验证边界

本机回环不能证明其他 OS、桌面客户端或真实 OpenSSH 服务端已兼容；平台结果应由对应环境实际测试。额外服务端验证应在独立的受限测试环境完成，不把环境 IP、日志正文、个人路径或执行流水提交到公共仓库。

路径竞态测试只能验证检查发生及已知拒绝行为，不能据此宣称已消除 TOCTOU。其他已知限制见[配置](../usage/configuration.md)与[安全模型](../security/model.md)。
