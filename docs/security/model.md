# 安全模型

## 信任边界

本地私有 YAML 定义允许连接的服务器、挂载及权限，只有授权用户应能编辑。工具入参不能增加主机、改变凭据或扩大目录。凭据不进入 MCP 响应、日志或 Git；环境变量和本地 YAML 都不构成加密或模型隔离。

远端文件名、属性、正文及 SSH banner 均是不可信数据。程序不会执行这些内容，Agent 也不应把文件中的指令当作系统或开发要求。

## 主机身份

每次握手强制校验所选 known_hosts，按解析后的真实主机名/IP 和端口匹配，不依赖反向 DNS 或其他别名的信任。

支持普通主机名/IP、逗号分隔的精确名称、非默认端口 `[host]:port`、IPv6、OpenSSH `|1|` 哈希记录，以及 Ed25519、ECDSA、RSA 公钥。比较原始公钥 blob，RSA 签名算法名称不会改变公钥身份。

匹配的 `@revoked` 公钥优先拒绝，`@revoked *` 可全局撤销公钥。主机证书、`@cert-authority`、普通信任记录的通配/否定模式或无法解析的记录会导致失败，不静默跳过。可手动选择仅包含必要可信记录的独立 knownHostsFile。

新主机或换钥时，从管理员或独立可信渠道核验指纹，再由用户登记到所选文件。ssh-keyscan 只能收集公钥，不能证明主机身份。程序不自动更新 known_hosts，也不允许关闭校验。

## 路径、权限与资源

- 所有文件工具经过统一授权入口。read 包含所有只读动作，write 包含创建/修改/移动等，delete 单独控制删除；默认只授予 read。跨挂载移动检查两端 write，解压检查源 read 与目标 write。
- 从远端 `/` 起逐段 lstat，覆盖 mount 所有祖先及用户路径；任何一段为符号链接都拒绝。
- 文件打开后通过 fstat 检查句柄类型，覆盖在校验后才截短；不操作设备、FIFO、socket 或类型不明的对象。
- 目录分批枚举，文件分块读写，搜索使用字面匹配和简单文件名模式；不提供任意命令执行或转发。挂载根不能移动或删除，递归动作须显式开启并先校验全树。
- 支持除 / 外的规范挂载，包括 /root。不存在按目录名称设置的隐式授权或黑名单；权限仍由用户配置与 OS 决定。
- 归档在本地解析，拒绝穿越、绝对/盘符路径、链接、特殊文件和冲突目标；限制压缩输入、展开总量和条目数，防止解压炸弹。ZIP 正文使用 CRC 校验，gzip 由 zlib 校验；不恢复归档的 owner/group 或特殊权限位。
- 排队、并发、时间、读写/扫描字节、递归条目、归档展开和输出有限额。搜索扫描预算独立于响应大小，不设置小型服务器/挂载数量或路径层数限制。取消/超时关闭该调用的 SFTP channel，故障不自动重放请求。
- 审计仅含合法 ID、工具名、受控错误码和计数；不记录路径、正文、密码、口令、私钥、Agent 端点、banner 或上游堆栈。YAML 错误不回显原文片段。

## 剩余风险

**MCP 路径策略不能代替远端 OS 权限隔离。** 同一 Agent 如果能通过其他工具直接使用 root SSH 凭据，就能绕过 MCP；普通账户也可能通过其他 SSH 入口使用其 OS 权限。

lstat 与后续打开之间存在 TOCTOU。打开后 fstat 为普通文件，也不能证明此前的所有路径段未被替换。客户端不能据此宣称原子 no-follow 或 chroot。恶意服务器还可以伪造属性与内容；检查以可信服务端实现为前提。

写入、覆盖、移动、递归删除和解压可能在错误、取消或断线前已经产生部分效果；错误中 mayHaveChanged 提示调用者核查，不保证回滚。write 能覆盖内容和重命名，delete 只单独控制删除工具，不能解释为“有 write 但绝不会丢失内容”。硬链接、并发进程和其他 SSH 入口仍需要 OS 级权限管理。

严格隔离使用专用受限账户、OS 权限和 SFTP chroot，只读场景可使用 internal-sftp 的只读选项。部署建议见[受限 SFTP 部署](deployment.md)。本项目不自动改变服务器配置。

格式与服务端约束参考 [OpenSSH known_hosts](https://man.openbsd.org/sshd.8#SSH_KNOWN_HOSTS_FILE_FORMAT)、[sshd_config](https://man.openbsd.org/sshd_config)。漏洞报告方式见[安全报告](../../SECURITY.md)。
